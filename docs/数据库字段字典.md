## 13. 状态机速查

**订单(status)**:
```
0 待确认 ──老师确认──→ 1 待收费 ──客服收费──→ 2 试课中 ──客服标记──→ 3 已完成
0 ──老师反悔──→ 5 已取消(需求回退 0,申请置 3)
任意收费前 ──家长放弃(管理端)──→ 5 已取消(需求关闭)
1 之后 ──家长放弃(管理端,退费)──→ 5 已取消(fee_status=2)
2 ──客服标记──→ 4 试课失败(fee_status=2,需求回退 0 或关闭)
```

**申请(status)**:0 申请中 → 1 被选中 / 2 已撤回(终态)/ 3 已排除(终态)/ 5 已失效(可重新投递新行);4 已试课未通过 → 1 可再选

**需求(status)**:0 接收申请中 ⇄ 2 已关闭(重开时对比 edit_version);0 → 1 已选定(生成订单)
