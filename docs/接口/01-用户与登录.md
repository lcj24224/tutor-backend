# 01 用户与登录(app-api)

> 通用约定与鉴权体系见 [00-全局约定与鉴权](00-全局约定与鉴权.md)。

## 1.1 登录与用户

| 接口 | 方法/路径 | 说明 |
|---|---|---|
| 微信登录 | POST `/app-api/auth/wechat-login` | 入参:`{code}`(wx.login)。后端 code2session 换 openid → 静默注册(无则建 t_user)→ 发 token。出参:`{accessToken, refreshToken, expiresTime, newUser: boolean}` |
| 首次选择身份端 | POST `/app-api/user/choose-role` | 入参:`{role: 1老师端/2家长端}`。仅 newUser 可调,记录默认视图偏好 |
| 我的资料 | GET `/app-api/user/profile` | 出参:昵称、头像、脱敏手机号 `138****1234`、身份状态(老师:cert_status;家长:publish_enabled) |
| 更新资料 | PUT `/app-api/user/profile` | 入参:`{nickname?, avatarUrl?}`;手机号单独走下方接口 |
| 绑定/修改手机号 | POST `/app-api/user/mobile` | 入参:`{mobile}`。AES 加密落库 + 写 mobile_hash;已绑定的修改需原手机号验证(自填制,无 getPhoneNumber) |

## 1.2 字典与行政区划

| 接口 | 方法/路径 | 说明 |
|---|---|---|
| 业务字典 | GET `/app-api/dict/data?type=subject` | 复用 yudao 字典接口,type ∈ subject/grade/education/eval_tag |
| 行政区划 | GET `/app-api/region/tree` | 省市区三级树,后端静态数据下发,前端一次拉取缓存 |

## 1.3 文件上传

| 接口 | 方法/路径 | 说明 |
|---|---|---|
| 图片上传 | POST `/app-api/file/upload` | multipart;复用 yudao infra 文件模块;限制类型(学生证/学信网/头像)、大小 ≤5MB;返回 URL |

## 1.4 动态墙与首页兜底

| 接口 | 方法/路径 | 说明 |
|---|---|---|
| 动态墙 | GET `/app-api/activity/feed` | 订单状态投影:`status IN (2,3)` join 需求,仅返回 区/学段/科目/状态/相对时间(**严格脱敏**),limit 20,Redis 缓存 |
| 首页兜底 | GET `/app-api/home/latest` | 用户拒绝定位时返回:Redis `home:feed:latest` 最新 50 条可见简历;Redis 无数据降级 DB |
