# 03 家长侧(app-api)

> 权限前提:家长身份 = `t_parent_profile.publish_enabled = true`(客服加微信审核后开通)。
> 订单接口见 [04-订单](04-订单.md)。

## 3.1 家长认证

| 接口 | 方法/路径 | 说明 |
|---|---|---|
| 发布权状态 | GET `/app-api/parent/status` | 出参:`{publishEnabled, wechatConfirmed}`;引导加客服微信(open-type=contact) |

## 3.2 需求

| 接口 | 方法/路径 | 说明 |
|---|---|---|
| 发布需求 | POST `/app-api/demand` | **权限:publish_enabled=true**;活跃需求 ≤3;review_status=0 待审核;geocoder 转坐标落库(前台不返回) |
| 编辑需求 | PUT `/app-api/demand` | 仅 status=2(已关闭)可编辑;**敏感字段(subjects/grade/address/hourly)→ review_status=0 强制不可见,edit_version+1;非敏感仅 edit_version+1 + 敏感词检测** |
| 关闭需求 | PUT `/app-api/demand/{id}/close` | status 0→2(closed_reason=家长手动下架);status=1 不可(需客服介入) |
| 重新打开 | PUT `/app-api/demand/{id}/reopen` | 2→0;**对比 edit_version:编辑过 → 存量申请(0/4)置 5 失效;未编辑 → 原申请保留**;review_status=1 才生效可见 |
| 我的需求 | GET `/app-api/demand/my-page` | 含每个需求的状态 |
| 申请列表 | GET `/app-api/demand/{id}/applications` | 老师简历卡片 + 申请时间;**简历隐藏的老师查询时排除**;未读红点:对比 Redis 中上次查看时间 |
| 选中老师 | POST `/app-api/demand/{id}/select` | 入参:`{applicationId}`;**生成订单(状态 0)+ demand status=1 + application=1,同一事务** |
