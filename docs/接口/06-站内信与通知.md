# 06 站内信与通知(app-api)

> 站内信定位:系统 → 用户**单向通知**(复用 yudao notify 体系),承载订阅消息覆盖不了的长文本(审核拒绝原因)、负向事件(失效/排除)与历史留痕。**用户间禁止互发(无接口,红线)。**
> 订阅消息(微信服务通知)4 个埋点见《产品设计文档》§6.2,发送失败 43101 静默忽略。

## 6.1 站内信接口

| 接口 | 方法/路径 | 说明 |
|---|---|---|
| 消息列表 | GET `/app-api/notify/message/page` | 复用 yudao notify;仅系统→用户单向 |
| 未读数 | GET `/app-api/notify/message/unread-count` | 红点角标 |
| 标记已读 | PUT `/app-api/notify/message/read` | |

## 6.2 发送场景清单(服务端触发,非接口)

| 场景 | 通道 |
|---|---|
| 认证/简历/需求审核结果(含拒绝原因) | 站内信(主)+ 订阅消息(唤醒) |
| 申请失效(需求编辑重开)/ 被排除(反悔)/ 举报处理结果 | 站内信 |
| 订单状态变化(选中/确认/收费/完成/失败) | 订阅消息(主)+ 站内信留痕 |
| 有老师申请你的需求 | 订阅消息(首条推送,后续靠红点) |
| 订阅消息额度用尽/授权被拒 | 站内信兜底 |

## 6.3 未读红点(Redis,不落库)

- 站内信未读数:复用 yudao notify 的已读状态
- 需求申请列表未读数:Redis 记录家长上次查看时间,对比 apply_at
