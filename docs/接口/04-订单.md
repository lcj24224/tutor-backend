# 04 订单(app-api)

> 订单状态机:`0 待确认 →(老师确认)→ 1 待收费 →(客服收费+发联系方式)→ 2 试课中 →(客服标记)→ 3 已完成 / 4 试课失败(先退费)/ 5 已取消`。完整流转见《数据库字段字典》§13。
> 管理端订单工作台接口见 [07-管理后台](07-管理后台.md)。

## 4.1 订单查询(双视角)

| 接口 | 方法/路径 | 说明 |
|---|---|---|
| 我的订单 | GET `/app-api/order/my-page` | 按 parent_user_id 或 tutor_user_id 双向查询,当前视图决定默认筛选;状态分组:待确认/待收费/试课中/已完成 |
| 订单详情 | GET `/app-api/order/{id}` | 仅当事人;**不含任何完整手机号**;含状态时间线(created/confirmed/paid/finished) |

## 4.2 老师侧状态操作

| 接口 | 方法/路径 | 说明 |
|---|---|---|
| 老师确认试课 | POST `/app-api/order/{id}/confirm` | 仅老师且 status=0;→1 待收费;触发订阅消息③(双方加客服微信) |
| 老师拒绝(反悔) | POST `/app-api/order/{id}/reject` | 仅老师且 status=0;→5 已取消;application→3;demand→0;break_promise_count+1(满 3 自动 blacklist);t_break_promise_log 留痕 |

> **红线:小程序端不存在任何"获取对方完整手机号"接口。联系方式仅客服后台可见、线下人工发放。**
