# 02 老师侧(app-api)

> 权限前提:老师身份 = `t_tutor_profile.cert_status = 2` 且 `blacklist = false`(服务端校验)。

## 2.1 老师认证

| 接口 | 方法/路径 | 说明 |
|---|---|---|
| 认证状态 | GET `/app-api/tutor/cert/status` | 出参:`{certStatus, rejectReason, auditAt}`;拒绝原因经站内信同步推送 |
| 提交认证 | POST `/app-api/tutor/cert/submit` | 入参:`{studentCardUrl, xuexinUrl}`;cert_status 0/3 → 1 待审核 |
| 重提认证 | POST `/app-api/tutor/cert/resubmit` | 仅 status=3 可调,材料覆盖,回 1 |
| 履约记录 | GET `/app-api/tutor/break-promise` | 出参:`{breakPromiseCount, appealStatus}`(仅自己可见) |

## 2.2 简历

| 接口 | 方法/路径 | 说明 |
|---|---|---|
| 我的简历 | GET `/app-api/tutor/resume` | 无简历返回 null |
| 创建简历 | POST `/app-api/tutor/resume` | 需 cert_status=2;创建后 review_status=0 待审核,visible=false |
| 编辑简历 | PUT `/app-api/tutor/resume` | **敏感字段(school/education/subjects)变更 → review_status=0 + 强制 visible=false;非敏感变更不重审**(走敏感词检测) |
| 可见性开关 | PUT `/app-api/tutor/resume/visible` | 入参:`{visible}`;仅 review_status=1 且非 blacklist 时可开 |
| 简历广场 | GET `/app-api/tutor/resume/page` | 筛选:distance(需经纬度)/subject/gender/education/hourlyRange;排序:平均分↓→举报核实↑→反悔↑→最近活跃↓;**默认全量最新 50 条兜底** |
| 简历详情 | GET `/app-api/tutor/resume/{id}` | 完整简历 + 平均分 + **公开评价列表(家长评老师,direction=1,status=1)** |
| 公开评价列表 | GET `/app-api/tutor/resume/{id}/evaluations` | 分页 |

## 2.3 需求广场(仅认证老师可见)

| 接口 | 方法/路径 | 说明 |
|---|---|---|
| 需求广场 | GET `/app-api/demand/page` | **权限:cert_status=2 且 blacklist=false**;筛选:distance/subject/grade/hourlyRange/genderReq;地址**只到区** |
| 需求详情 | GET `/app-api/demand/{id}` | 同上权限;不含详细地址/坐标/家长联系方式 |
| 投递申请 | POST `/app-api/application` | 入参:`{demandId}`;**校验:认证通过、非黑名单、需求 status=0 且 review_status=1、禁止自我成交(parent_user_id ≠ 自己)、无 status IN (0,1,2,3,4) 的存量申请** |
| 撤回申请 | PUT `/app-api/application/{id}/withdraw` | 仅 status=0(家长未选前);**撤回后终态,不可重投该需求** |
| 我的申请 | GET `/app-api/application/my-page` | 按状态筛选;失效(5)可见"已失效"标记 |
