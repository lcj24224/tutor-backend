# 07 管理后台(admin-api,客服工作台)

> 权限:yudao RBAC(system_users 客服账号 + 角色/菜单);MVP 单人客服。完整手机号/详细地址**仅本模块有权解密**。
> 所有人工操作留痕 `t_audit_log`(含 operator_id)。

## 7.1 用户管理

| 接口 | 方法/路径 | 说明 |
|---|---|---|
| 用户分页 | GET `/admin-api/user/page` | 昵称/状态筛选;**mobile 参数:按 mobile_hash 等值查找** |
| 用户详情 | GET `/admin-api/user/{id}` | **完整手机号解密展示(唯一有权位置)** |
| 封禁/解封 | PUT `/admin-api/user/ban` | 用户级,两端全封;留痕 audit_log |
| 身份视图 | GET `/admin-api/user/{id}/profiles` | 老师/家长身份状态一览 |

## 7.2 老师审核

| 接口 | 方法/路径 | 说明 |
|---|---|---|
| 认证待审列表 | GET `/admin-api/tutor/cert/page` | cert_status=1 |
| 认证审核 | PUT `/admin-api/tutor/cert/audit` | 通过(cert_status=2)/拒绝(3+原因);**写站内信通知结果+原因**;留痕 |
| 简历审核列表 | GET `/admin-api/tutor/resume/review-page` | review_status=0 |
| 简历审核 | PUT `/admin-api/tutor/resume/review` | 通过(1)/拒绝(2+原因);通过后 visible 自动恢复为用户开关值 |

## 7.3 家长审核

| 接口 | 方法/路径 | 说明 |
|---|---|---|
| 家长列表 | GET `/admin-api/parent/page` | 待开通筛选(wechat_confirmed 未确认) |
| 开通发布权 | PUT `/admin-api/parent/publish-enable` | publish_enabled=true + 备注;留痕 |

## 7.4 需求管理

| 接口 | 方法/路径 | 说明 |
|---|---|---|
| 需求分页 | GET `/admin-api/demand/page` | 全状态;**完整地址可见(唯一有权位置)** |
| 需求审核 | PUT `/admin-api/demand/review` | review_status=0 的审核通过/拒绝+原因;站内信通知 |
| 强制下架 | PUT `/admin-api/demand/{id}/force-close` | 举报核实后;closed_reason=举报核实 |

## 7.5 订单管理(核心工作台)

| 接口 | 方法/路径 | 说明 |
|---|---|---|
| 订单分页 | GET `/admin-api/order/page` | 状态/费用状态筛选;**待收费(status=1)为收款工作台入口** |
| 订单详情 | GET `/admin-api/order/{id}` | **双方完整手机号(唯一有权位置)**、fee 时间线、fail_blame |
| 收费登记 | PUT `/admin-api/order/{id}/collect-fee` | status 1→2;fee_status→1;fee_collected_at=now;**与发放联系方式同一动作** |
| 退费登记 | PUT `/admin-api/order/{id}/refund` | fee_status→2;fee_refunded_at=now(试课失败/收费后取消场景) |
| 标记完成 | PUT `/admin-api/order/{id}/mark-finished` | status 2→3;finished_at;demand→2(closed_reason=已完成) |
| 标记试课失败 | PUT `/admin-api/order/{id}/mark-failed` | status 2→4;**必填 fail_blame(1老师/2家长)+ fail_reason**;强制先退费(fee_status=2);demand 按家长意愿:回 0(还要老师)或关 2(不要了) |
| 管理端取消 | PUT `/admin-api/order/{id}/cancel` | 家长放弃场景;收费前直接取消,收费后先退费再取消;demand→2(closed_reason=家长放弃);留痕 audit_log(target_type=order) |

## 7.6 评价/举报/反悔/统计

| 接口 | 方法/路径 | 说明 |
|---|---|---|
| 差评审核 | PUT `/admin-api/evaluation/audit` | status 0→1 公开 或 2 隐藏;申诉处理 |
| 举报列表/处置 | GET+PUT `/admin-api/report` | 核实成立 → 目标 profile.report_count+1 + 强制下架其简历/需求 + 站内信通知 |
| 反悔管理 | GET `/admin-api/tutor/break-promise/page` | 计数查看、blacklist 强制下线、申诉恢复(计数清零,历史保留) |
| 统计看板 | GET `/admin-api/stat/dashboard` | 注册数/申请数/订单数/完成率(简单统计) |
