## 模块边界

1. C 端接口前缀 `/app-api/**`;管理端 `/admin-api/**`;Header 统一 `Authorization: Bearer {token}`。
2. 登录/资料/字典/文件/动态墙归 01 用户与登录模块。
3. 需求广场的浏览/投递/撤回归 02 老师侧;需求单的发布/编辑/关闭/申请列表/选中归 03 家长侧。
4. 订单的查看与状态操作统一归 04 订单模块(含老师确认/反悔、家长视角列表)。
5. 评价与举报归 05;审核结果/失效/排除等长文本通知走 06 站内信。
6. 客服工作台全部接口归 07 管理后台。
7. **防跳单红线:小程序端任何接口不返回完整手机号/详细地址/坐标(见 00 安全矩阵)。**

## 演进约定

- 字段级请求/响应 JSON 合同在**各模块开发时随代码一起细化**(代码未写前字段会变,不提前冻结)。
- 接口变化必须同时更新对应模块文档,与代码同一提交(见《文档索引》维护规则)。
